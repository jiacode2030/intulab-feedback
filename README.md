# AP Science Labs feedback

One shared issue tracker for every AP Science Labs site: the [landing page](https://jiacode2030.github.io/ap-labs/) and each course.

Each site's **Report an issue** link opens a pre-filled issue here. You can also [open one directly](https://github.com/jiacode2030/ap-labs-feedback/issues/new/choose) and pick **Content error**, **Bug** or **Suggestion**.

Issues are labelled by course (`course:mechanics`, `course:em`, `course:chem`, `course:landing`) and by type (`type:content`, `type:bug`, `type:suggestion`).

Issues are public, so please don't include personal information.
